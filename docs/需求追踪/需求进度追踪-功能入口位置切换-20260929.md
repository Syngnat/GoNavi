# 需求进度追踪 - 功能入口位置切换

## 1. 需求摘要
- 需求名称：标题栏功能入口位置与显示方式切换
- 提出日期：2026-09-29
- 负责人：Claude Code
- 目标：「新建连接 / 新建查询 / 管理连接分组 / 数据工作流 / SQL 工具 / 用户管理 / AI」这一行入口可在设置中切换位置：标题栏下方独立工具条（图标 + 文字），或标题栏 GoNavi 右侧；放在标题栏时可选纯文字 / 纯图标 / 图标 + 精简文字
- 默认值：新用户为「标题栏 GoNavi 右侧 + 图标 + 文字」；老用户升级后保持工具条，切到标题栏时默认纯文字
- 非目标：调整按钮顺序与数量；改动设置 / 主题 / 驱动管理 / 关于在标题栏右侧的位置；macOS 原生菜单栏

  - 运行时切换不丢失 Sidebar 通过 portal 注入的快捷入口
- 验收标准：
  - 新安装：标题栏 + 图标 + 精简文字；老配置升级：界面与升级前一致

  - 各模式下所有入口可点击；纯图标 / 图标 + 文字模式悬停可见完整名称
- 依赖与约束：App.tsx / store.ts 为超标文件，净行数不得增加；文案走 shared/i18n

## 6. 决策记录
- 决策 1：设置放在 appearance 分片（与 DataGridDisplaySettings 同模式），store.ts 只做展开接线
- 决策 2：标题栏模式复用 App.css 保留的旧标题栏样式，显示方式只用作用域 CSS 切换，不改组件结构
- 决策 3：新用户与老用户区分依据是持久化 appearance 是否存在：首次启动 persist merge 收到空 appearance 走默认值（标题栏 + 图标 + 文字），已有配置缺字段走回退值（工具条 + 纯文字）
- 决策 4：精简名称只在标题栏形态注入 DOM，工具条结构与之前完全一致
