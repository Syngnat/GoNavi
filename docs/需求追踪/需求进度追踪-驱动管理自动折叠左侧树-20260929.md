# 需求进度追踪 - 驱动管理自动折叠左侧树

## 1. 需求摘要
- 需求名称：打开驱动管理时自动折叠左侧树，关闭后自动展开
- 提出日期：2026-09-29
- 负责人：Claude Code
- 目标：点击「驱动管理」打开标签页时折叠左侧树，给驱动列表让出宽度；关闭驱动管理后恢复左侧树
- 非目标：其他设置分页、其他工作台标签页的侧栏行为；侧栏折叠状态持久化

## 2. 范围与验收
- 范围：
  - 「驱动管理」有两种形态：标题栏按钮打开的设置中心「驱动管理」分页、从连接配置打开的独立 `driver-manager` 标签页，两者都算
  - 进入（打开或切回）驱动管理时折叠；离开（关闭标签页、切到其他标签页或设置分页）时展开
- 验收标准：
  - 左侧树原本展开：打开驱动管理后折叠，关闭后展开
  - 左侧树原本折叠：打开、关闭驱动管理都保持折叠
  - 驱动管理显示期间手动展开过左侧树：离开时不再干预
  - 自动折叠不抢焦点，不闪现
- 依赖与约束：App.tsx 为超标文件，净行数不得增加

## 6. 决策记录
- 决策 1：以「驱动管理正在显示」为条件而非「标签页存在」，切到查询等标签页时左侧树自动回来
- 决策 2：只恢复自己折叠的状态，显示期间用户手动展开视为接管
- 决策 3：自动折叠不走手动折叠的焦点交接，只让出树内焦点；用布局副作用在绘制前完成
