## 1. 需求摘要
- 需求名称：SQL 执行历史页面重做；编辑器工具栏「历史/诊断/慢 SQL」入口外露；慢 SQL 与 SQL 诊断页面重做；三个页面颜色跟随应用主题

## 6. 决策记录
- 决策 1：历史页与审计中心拆成两个组件，而不是继续在 `SqlAuditWorkbench` 里堆 `queryHistoryMode` 分支。
- 决策 2：用状态分段器（带计数）取代四个汇总卡片，把纵向空间让给列表；选中非「全部」状态时额外发一次不带状态的汇总请求维持计数。
- 决策 3：工具栏入口用「文字标签 + 下拉」而不是三个图标按钮，避免工具栏继续变宽。
- 决策 4：工作台面板底色取查询工作台同款表面 `--gn-query-workbench-bg`（缺省 `--gn-bg-panel-2`），而不是 `--gn-bg-panel`：后者在多数内置主题里近乎纯白（如淡紫主题 panel=#fbfafd、panel2=#f4f0f8），会让整页看起来没有主题色，也和 SQL 编辑器/结果区/日志面板不一致。
- 决策 5：诊断失败提示条不再放「重试诊断」，重试入口统一为上方 SQL 栏的「重新诊断」（删除 `sql_analysis.explain.action.retry`）。
